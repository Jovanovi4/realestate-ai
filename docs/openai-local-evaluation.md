# Локальная проверка OpenAI API — 6 октября 2026

Проверка выполнена через `AIService` на вымышленных карточках продажи квартиры и долгосрочной аренды. Реальные клиентские данные и браузер не использовались. Ключ находится только в локальном файле, исключённом из Git; в отчётах его нет. Тестовые вызовы не создавали записи в CRM.

## Выбор модели

Для локального режима выбран `gpt-6-luna` с `reasoning.effort=none`. Она вернула все девять частей комплекта по обоим объектам, не добавила неподтверждённых характеристик и сохранила различие между продажей и арендой. Отдельные генерация и улучшение текста также прошли.

| Один и тот же комплект для тестовой продажи | Входные токены | Выходные токены | Расчётная стоимость |
| --- | ---: | ---: | ---: |
| `gpt-6-luna`, `none` | 663 | 309 | $0,0002208 |
| `gpt-4.1-mini` | 664 | 342 | $0,0008128 |

Расчёт сделан по стандартным ценам за текстовые токены на дату проверки: [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) и [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini). Реальная стоимость зависит от длины карточки, ответа, кэша и текущего тарифа API. Кредиты продукта остаются отдельными условными единицами.

На примере аренды `gpt-4.1-mini` добавила неуказанное «готова к проживанию» и превысила заданные 60 символов SEO-заголовка. Существенного преимущества в качестве за более высокую цену на этой маленькой выборке не видно. Это не заменяет дальнейшую проверку на разнообразных объектах.

## Исправления промптов

- Короткое описание ограничено 450 символами без обязательного минимума: при скудных данных модель не повторяет факты ради длины.
- Полное описание допускает 1–3 абзаца и опирается на все известные сведения без повторов.
- Текст блока «Почему выбирают нас» теперь берёт факты из возможностей сервиса, а не пересказывает характеристики недвижимости. Он остаётся общим: персональные преимущества риелтора можно добавлять только после передачи подтверждённых сведений о нём.

Автоматические тесты проверили формат запроса OpenAI, сохранение токенов в учёте, неполный комплект и таймауты. Полный прогон: 466 тестов, 2 пропущены, ошибок нет. Настройки хостинга и платежей не менялись.
