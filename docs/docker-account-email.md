# Письма учётной записи на Docker-пилоте

Подтверждение email и восстановление доступа используют очередь
`AccountEmailRequest`. Веб-запрос только ставит письмо в очередь; сервис
`account-emails` отправляет её каждую минуту. Для пилота с Яндекс Почтой
включите доступ почтовых программ и создайте отдельный пароль приложения
типа «Почта». Пароль не помещайте в Git, чат или команды shell.
Яндекс предупреждает, что новый пароль приложения может начать действовать
через 2–3 часа; при ранней ошибке авторизации повторите проверку позже.

В приватном `.env.docker` на VPS задайте:

```dotenv
EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465
EMAIL_HOST_USER=логин_почтового_ящика
EMAIL_HOST_PASSWORD=пароль_приложения
EMAIL_USE_TLS=False
EMAIL_USE_SSL=True
DEFAULT_FROM_EMAIL=полный_адрес_ящика
```

Для `@yandex.ru` логином обычно служит часть адреса до `@`; для Яндекс 360
на собственном домене укажите полный адрес. `DEFAULT_FROM_EMAIL` должен
совпадать с адресом ящика, через который проходит SMTP-авторизация.

`EMAIL_NOTIFICATIONS_ENABLED=False` можно оставить: этот флаг управляет
почтовыми уведомлениями о заявках, а не письмами учётной записи. Сначала
проверьте конфигурацию без вывода подставленных значений:

```sh
chmod 600 .env.docker
sudo docker compose --env-file .env.docker config --quiet
```

После обновления образа перезапустите `web`, затем включите профиль `mail`:

```sh
sudo docker compose --env-file .env.docker up -d --no-build --force-recreate web
sudo docker compose --env-file .env.docker --profile mail up -d --no-build account-emails
```

В личном кабинете тестового пользователя сохраните доступный вам email и
запросите подтверждение. Письмо должно появиться в течение минуты. Откройте
ссылку из письма и подтвердите адрес. Затем проверьте `email_verified_at`
и Демо-грант через `billing_usage_report`: ожидаются 5 выделенных разовых
кредитов, если пользователь ещё не получал грант. Старый расход в теневом
режиме не списывается задним числом. При отсутствии письма проверьте статус
сервиса `account-emails`, очередь и папку «Спам»; не печатайте текст письма
или его ссылку в общие журналы.

Параметры Яндекса: [SMTP и почтовые программы](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others),
[пароли приложений](https://www.yandex.ru/support/id/ru/authorization/app-passwords).
