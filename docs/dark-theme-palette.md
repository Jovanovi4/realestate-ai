# Тёмная палитра CRM

Ветка: `dark_design`. Контрольный экран: список заявок с открытой миникарточкой.
Значения задаются в `static/css/rieltor-ui.css`, в блоке `:root[data-bs-theme="dark"]`.

Ошибка в поле выделяется контрастной границей `#FDA29B`; границы сообщений мягче.
Все состояния сопровождаются текстом. У срочной строки остаётся красная полоса,
у открытой карточки — подчёркнутое имя, у массового выбора — отмеченный чекбокс.
Чекбокс с полным или частичным выбором: светлый фон `#D0D5DD`, тёмная отметка `#101828`.

## Общий механизм темы

- Источник настройки — `RealtorProfile.color_scheme`: `light`, `dark`, `system`.
  Миграция `0067_realtorprofile_color_scheme` задаёт светлую тему существующим профилям.
- Отдельный POST `/profile/appearance/` сохраняет только тему текущего пользователя
  с проверкой входа, CSRF и допустимых значений. Контактные данные не затрагиваются.
  Другая сессия этого аккаунта получает настройку при следующей загрузке страницы.
- Сервер выставляет `data-color-scheme` и начальный `data-bs-theme` на `<html>`.
  Ранняя мета-настройка `color-scheme` сообщает браузеру цветовую схему до загрузки CSS.
  Синхронный `color-scheme.js` в `<head>` разрешает системную тему до всех таблиц стилей.
  Фон самого документа также использует `--ui-canvas`.
- При изменении настройки устройства `matchMedia` обновляет оформление только в режиме
  `system`. Явно выбранная светлая или тёмная тема сохраняется. Во время переключения
  синхронно обновляются атрибут Bootstrap и мета-настройка браузера.
- При ошибке или тайм-ауте сохранения интерфейс возвращается к последнему подтверждённому
  выбору и показывает сообщение с предложением повторить действие.
- CSS-переменные Bootstrap для текста, фона и ссылок согласованы с палитрой, включая
  отдельные RGB-каналы для вспомогательных классов. В тёмном режиме смысловые состояния
  `*-text-emphasis`, `*-bg-subtle`, `*-border-subtle` также используют палитру CRM.
- `--ui-accent` / `--ui-accent-hover` отвечают за текстовые акценты;
  `--ui-primary-fill` / `--ui-primary-fill-hover` — за заливку основной кнопки;
  `--ui-on-accent` — за текст на ней. Их нельзя объединять при дальнейшей адаптации.

Реализация следует [механизму цветовых режимов Bootstrap 5.3](https://getbootstrap.com/docs/5.3/customize/color-modes/).
Настройка не хранится в `localStorage`: аккаунты на одном устройстве не наследуют выбор друг друга.
Без JavaScript явная тема применяется сервером, а режим `system` использует светлую
тему; сохранение доступно обычной кнопкой отправки формы.

Проверки механизма: `properties.test_profile_appearance` (включая независимые сессии,
порядок загрузки и HTMX), `properties/tests_js/color_scheme.test.cjs` (переключение,
системные события и ошибки), `properties.test_ui_palette` (контраст и RGB-соответствие).

Проверки: `properties.test_ui_palette`, сценарий тёмной страницы и HTMX в
`properties.test_profile_appearance`, существующие сценарии обработки заявок.

Для ручной приёмки: включить тёмную тему в личном кабинете, открыть заявку из списка,
раскрыть форму контакта, проверить наведение и клавиатурный фокус, выбрать одну и несколько строк.
На телефоне проверить те же состояния в карточках списка.

## Адаптация разделов

| Область | Что использует общую тему |
| --- | --- |
| Общие элементы | Боковое и мобильное меню, фон документа, карточки, поля, кнопки и их недоступные состояния, вкладки, меню действий, подсказки, диалоги и затемнение |
| Ежедневная работа | Задачи, заявки покупателей и собственников, клиенты, воронка сделок, полные карточки и боковые формы |
| Другие разделы | Каталог объектов, галерея и её кнопки, редактор текстов и лендинга, аналитика, команда, история, тариф, профиль, интеграции |
| Особые состояния | Ошибки полей и отправки, просрочка, выбранные и наведённые строки, пустые списки, отсутствие фотографии, загрузка и недоступность действий |

В тёмной теме меню имеет фон `#182230`, а выбранные пункты — `#344054`.
Оттенки этапов «Показ», «Переговоры» и «Бронь» сохранены по смыслу, но осветлены
для графитового фона. Текст всех заполненных статусов сделок переключается отдельно
через `--ui-on-status`; контраст проверен для всех семи этапов в обеих темах.
Переключатели редактора сохраняют круглую отметку, чекбоксы — галочку.

Миниатюры дизайна лендинга, образцы его цветов и содержимое iframe показывают
собственное оформление лендинга. Тёмной становится рамка редактора и его управление.
Публичные шаблоны не подключают CSS или JavaScript темы CRM. У публичных форм подбора
и собственника тема аккаунта также отключена, даже если риелтор уже вошёл в CRM.

`properties.test_workspace_theme` проверяет серверный вывод 24 внутренних экранов
в светлой и тёмной теме, пустые состояния, три вида боковых карточек, ошибки формы,
просроченную задачу и независимость трёх публичных шаблонов и предпросмотра.
Эти проверки не заменяют визуальную приёмку: браузер в этом этапе не открывался.

## Компактные элементы рабочего пространства

- В задачах просрочка отмечена красной точкой у названия; рамка и фон группы обычные.
- Поиск заявок и клиентов всегда виден перед фильтрами, без отдельной подложки. Результаты обновляются после паузы при вводе.
- Выбор темы находится под блоком «Доступ к аккаунту»: три компактных значка с подписями и отметкой выбранного варианта.
